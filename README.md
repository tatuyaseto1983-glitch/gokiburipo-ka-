# ごきぶりポーカー（スマホ用アプリ）

2〜6人で遊べます。手札は自分のスマホにだけ表示されます。

## 遊び方（カードの代わりに使うアプリ）
アプリがやるのは「手札を見る」「カードを渡す」だけ。**宣言と「ホント／ウソ」は声で言います。**

1. `npm install` → `npm start`（ポート3000）。または公開したURLを全員のスマホで開く
2. 1人が「部屋をつくる」→ 4けたの部屋コードをみんなに伝え、他の人はコードで入る
3. ホストが「ゲーム開始」
4. 自分の番：渡すカードと相手を選んで「渡す」。同時に声で「これはカエル」などと宣言する
5. 渡された人：声で「ホント／ウソ」と答えて「めくる！」。または「こっそり見て、別の人に回す」（回すときも声で宣言）
6. めくると全員にカードが見える。言った通りなら「当たった！」（渡した人が引き取り）、違えば「外れた…」（自分が引き取り）を押す

## 負けの条件
同じ種類が4枚そろう／8種類すべてそろう／自分の番で手札がない

※カードが割り切れない人数のときは、余りは使いません。
