# ごきぶりポーカー（スマホ用アプリ）

2〜6人で遊べます。手札は自分のスマホにだけ表示されます。

## 遊び方
1. `npm install` → `npm start`（ポート3000。`PORT` で変更可）
2. 全員のスマホで同じアドレスを開く（同じWi-Fi内なら `http://<このPCのIP>:3000`）
3. 1人が「部屋をつくる」→ 4けたの部屋コードをみんなに伝える
4. 他の人はコードで入り、ホストが「ゲーム開始」
5. 自分の番：カード・いう生き物・渡す相手を選んで「渡す」
6. 渡された人：「ホント／ウソ」で答える、または「こっそり見て別の人に回す」
7. 答えた人が「めくる」を押すと、全員の画面でカードがめくられる（実物のカードがないときの代わり。テーブルを囲んで遊ぶ想定）

## 負けの条件
同じ種類が4枚そろう／8種類すべてそろう／自分の番で手札がない

※カードが割り切れない人数のときは、余りは使いません。
